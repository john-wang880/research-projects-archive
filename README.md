# TCAD Simulation Archive

This archive contains four Sentaurus/TCAD projects copied from the public repositories owned by [Greatlovers](https://github.com/Greatlovers). The source repositories remain unchanged.

## Projects from the TCAD collection

- **CS-SJ-IGBT** — 650 V trench field-stop charge-storage super-junction IGBT reproduction. See [project README](training/CS-SJ-IGBT/README.md), [Workbench export](training/CS-SJ-IGBT/CS-SJ-IGBT.gzp), and [results dashboard](training/CS-SJ-IGBT/figures/fig_07_results_dashboard.png).
- **RC-IGBT** — reverse-conducting IGBT Sentaurus project. See [project README](training/RC-IGBT/README.md), [sanitized Workbench package](training/RC-IGBT/RC-IGBT_swb_project_sanitized.zip), and [PDF guide](training/RC-IGBT/rc_igbt_project_documentation.pdf).

## Additional standalone projects

- **dynamic-CBL-IGBT-3D** — [source repository](https://github.com/Greatlovers/dynamic-CBL-IGBT-3D); includes a no-material-parameters archive. See [local project folder](projects/dynamic-CBL-IGBT-3D/).
- **4H-SiC micro-hole UV photodiode arrays** — [source repository](https://github.com/Greatlovers/reproduction-of-high-speed-4h-sic-micro-hole-uv-photodiode-arrays); includes Sentaurus source templates and setup utilities. See [local project folder](projects/reproduction-of-high-speed-4h-sic-micro-hole-uv-photodiode-arrays/).

## Requirements and notices

Rerunning these projects requires a valid local Sentaurus/Synopsys installation and license. Some source projects intentionally exclude material parameter files, optical material tables, and generated states; see each project's README before running. Preserve the original license and notice files in each copied project. Third-party paper excerpts and other third-party content remain subject to their owners' rights; this archive grants no additional rights.
